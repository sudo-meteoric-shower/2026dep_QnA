# 本地语音问答助手 · 模态扩展

本分支在课堂复现版上加入本地图片识别和图文检索。原有文字问答、Whisper 语音识别、BGE 向量和 Qwen 回答继续使用。上传图片时，SmolVLM 只负责生成可以入库的图像说明。

## 使用

1. 如果是新克隆，先执行 git lfs pull 获取基础模型。在 voice_qa_local 目录运行 python download_vision.py 获取固定版本的视觉模型。程序按官方 SHA-256 校验模型权重，运行阶段从本地读取。需要代理时可通过环境变量 HTTPS_PROXY 指向已有代理。
2. 双击 voice_qa_local/启动本地服务.bat，点击「全部加载」。确认向量模型就绪后上传 PNG、JPEG 或 WebP，单张图片至多 8 MB、最长边至多 4096 像素。
3. 状态显示图片已入库后，启用 RAG 和「检索图像说明」，提问。命中时可查看原图及自动生成的说明。自动说明可能有误，标为「待核对」。
4. 若已有本地课本图文索引，可在 voice_qa_local/course_sample 放入样例清单及原图，再点击「加载空气动力学示例」。

## 运行配置

- 当前默认文字模型是 Qwen3-0.6B。SmolVLM-256M-Instruct 使用固定版本 a1a065473baa55316b2ddf85ae4e29282d89ad12，ONNX 权重约 210 MB，用 WASM 运行。
- 检索综合 BGE 相似度、图题词面覆盖和对象标签命中。明确写图号时限定到该图；主图命中时只关联同图正文，减少不相关图的文字干扰。
- 手工复核说明和自动读图是两种输入。课本样例、图片和本机验证输出是本地材料。模型安装一次后，图片解析和问答可在离线环境运行。
