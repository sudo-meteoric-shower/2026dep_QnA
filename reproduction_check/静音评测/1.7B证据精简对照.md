# 1.7B 原句精简对照

基线为远端 1_7_try 的 f75e5c5。使用 Qwen3-1.7B q8、CPU WASM、BGE-small 与冻结的六道合成资料题。每题在同一浏览器和同一模型实例上分别运行完整与精简上下文，交替改变先后顺序。原始 Top-3 内容和顺序逐题比对一致，引用显示完整片段，生成与清洗参数一致。浏览器静音，启动前可用显存 7957 MiB、内存 11865 MiB，记录到 0 次外部请求、失败请求和浏览器错误。

方法借鉴 RECOMP 在检索后选取原句的方向。实验用简单的中英文字符双字词重合，至少重合两组时选取最高分的原句，分数偏低或有多行结构时保留全文。LongLLMLingua 的实验说明可以测上下文缩减对时延的影响，本例输入约两百多个 token，须单独实测。ONNX Runtime Web 的性能诊断指南支持按阶段比较瓶颈。[RECOMP](https://proceedings.iclr.cc/paper_files/paper/2024/hash/bda88ed2892f5e61c9a9bf215c566913-Abstract-Conference.html) · [LongLLMLingua](https://aclanthology.org/2024.acl-long.91/) · [ONNX Runtime Web 性能诊断](https://onnxruntime.ai/docs/tutorials/web/performance-diagnosis.html)
