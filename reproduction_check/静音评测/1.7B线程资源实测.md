# Qwen3-1.7B 线程与资源实测

本机为 Intel Core i9-14900HX，24 物理核、32 逻辑处理器，独显为 RTX 4060 Laptop GPU。开始、途中及结束的电源检查均为电池供电与 Windows 平衡计划。沿用 1.7B q8、BGE-small、原题、CPU WASM 和独立的静音 Edge 测试进程。线程数按 4、8、12、16 运行，再倒序复测 16、4。每轮从新浏览器实例开始，答题时间从提交问题起算。

充电时长题输入 225 token、输出 4 token。采样数量题输入 235 token、输出 73 token。两种配置完成的长题与短题输出均逐字一致。上一轮十几秒的数字属于单道充电题，先前约 47 秒是另一批六题平均值，测量对象与系统负载有差别。

| 线程 | 充电题完整回答 | 采样题完整回答 | 最低可用系统内存 | 系统 CPU 峰值 |
| ---: | ---: | ---: | ---: | ---: |
| 4 | 27.99 / 10.58 秒 | 134.70 / 71.66 秒 | 6652 MiB | 36% |
| 8 | 34.77 秒 | CDP 等待超时 | 7622 MiB | 31% |
| 12 | 39.41 秒 | CDP 等待超时 | 7824 MiB | 45% |
| 16 | 7.71 / 7.84 秒 | 94.95 / 79.77 秒 | 7054 MiB | 70% |

941 个一秒间隔采样中，独显占用峰值 1%，驱动报告的显存使用峰值 57 MiB，最低可用显存 7901 MiB。GPU 数据来自整机采样。资源保护设为可用系统内存低于 4096 MiB 或驱动报告可用显存低于 1024 MiB 连续两次，触发后停止本次测试。所有轮次均未触发保护。8 和 12 线程的长题超时属于评测工具等待失败，记录未显示显存或内存不足。

16 线程在两个短题样本上均更快，两轮长题的快慢次序不同。当前通用设置仍使用 4 线程，短答低延迟场景可优先继续验证 16 线程。建议在独立的接电工况下重复少量固定题，再决定是否有必要对照厂商性能模式。WASM 的线程数属于会话创建前的全局配置，改变线程设置后须重建会话。测试中的等待时间不能用来判断每个档位的能耗。[ONNX Runtime Web 线程设置](https://onnxruntime.ai/docs/tutorials/web/env-flags-and-session-options.html) · [NVIDIA 系统监控说明](https://docs.nvidia.com/deploy/nvidia-smi/index.html)
