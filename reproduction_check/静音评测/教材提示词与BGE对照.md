# 教材提示词与 BGE 检索对照

使用《控制工程导论》第 4 版书页 2～10（PDF 第 12～20 页）。该 PDF 共 270 页，抽查页的 PDF.js 文本层为空。逐页用本机 Windows 中文 OCR 转写，并对照扫描图核定标准答案。输入保留 OCR 的原有识别误差。两个向量模型各自建库，同一批 9 份文本均得到 35 块。数据限于本章样页。

固定 Qwen3-1.7B q8、4 个 CPU WASM 线程、360 字符分块与 60 字符重叠、Top-3、80 个生成 token 上限和相同清洗。每个问题在同一模型实例内交替先测一种指令，两种指令收到的三个检索片段及排序逐题相同。换 BGE 后新开浏览器、从头建库。先用 8 份模拟材料做对照，再测预先写好答案的 6 道教材新题。

原指令的末句为「请只给出有依据的答案。」第一轮候选为「第一句直接回答问题。照原文保留数值、单位、比较关系和全部必要条件。资料没有说明时答“资料中未提及”。」只替换 RAG 用户消息的末句。

## 检索与答案依据

5 道有标准依据的教材题，两种 BGE 均 5/5 首位命中正确页。按实际片段是否包含全部必要信息重评，small 的 Top-1、Top-3 分别为 4/5、5/5，base 为 2/5、4/5。拒答题不进入检索分母。逐题核查两个提示均显示来源列表。列表包含证据与模型是否正确引用、使用该证据分别判断。

| 题目 | 完整证据的首个排名 small／base | 典型结果 |
| --- | --- | --- |
| 瓦特年份 | 1／1 | 正确年份为 1788。base 的原指令答对，简答改写成 1988。 |
| 发电机输出变化 | 2／未命中 | base 首位命中书页 4，却漏掉列全三个因素的片段。small 加简答答全激磁电压、原动机转速和负载。 |

## 第二条候选与回归

固定 BGE-small，另试「按资料原词用一行答完。多项用顿号隔开，数字、单位和条件照录；查不到就答“资料中未提及”。」三道独立新题的正确数由 1/3 到 2/3。复合控制题同时答出了名称和两项性能。人工控制题在三项工作之外多列了“控制器”，计错。另重跑已看过的开环控制题，候选给全了三个条件，又把不可预期扰动时的建议写反，两种指令都计错。四次作答合并均耗时由 85.57 降至 59.68 秒。

第一轮简答配 small 回归原 9 题，按原评测的核心答案口径 9/9，平均 29.03 秒。退出备用模式题写成“恢复到11伏”，原文的“达到或超过”未充分表达；压力计算给出 150，但末句截断。数字答对和话语完整度仍需分别考察。

本批优先保留 BGE-small。第一轮简答作为 1.7B 可复现的优化候选：教材均耗时缩短约 15.6%，多答对一题；模拟总分持平，锁阀条件一题由对变错。两种候选均有逐题回退，正式页面沿用原指令。实验数据未覆盖整本教材、其他课程或 0.6B。

## 复现入口

先在项目根目录用 Windows PowerShell 5.1 执行 `reproduction_check/prepare_control_fixture.ps1 -PdfPath <本地教材路径>`。需要 pdftoppm 和系统中文 OCR。随后依次运行下面两条命令。原始教材、扫描图和含原文的本地明细位于本机，本地结果命名可由 result-tag 指定。

```powershell
node reproduction_check/verify.cjs --compare=candidate --model=qwen3_17b --wasm-threads=4 --monitor-resources --study-set=control --study-emb=small --result-tag=my-study-small
node reproduction_check/verify.cjs --compare=candidate --model=qwen3_17b --wasm-threads=4 --monitor-resources --study-set=control --study-emb=base --result-tag=my-study-base
```

模拟材料使用 `--study-set=simulation`。一行摘答验证使用 `--study-set=hold --study-emb=small`。本轮共 57 次静音文字作答，6 个批次均通过资源预检，无浏览器异常、失败请求或外网请求。详见[逐题判分与耗时](study-scores.json)、[教材题与标准答案](study-control.json)和[原九题回归](candidate-study-regression-small.json)。
